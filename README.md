# Insurance Claim Fraud Detection Project

## Project Overview
This project focuses on detecting fraudulent vehicle insurance claims using machine learning techniques. The objective is to support investigation triage by identifying high-risk claims and optimizing decision thresholds based on cost trade-offs.

---

## Project Stages

1. **Data Collection**
   - Dataset obtained from Kaggle (Vehicle Insurance Claim Fraud Detection dataset)

2. **Data Preparation**
   - Handling missing values
   - Encoding categorical variables
   - Feature scaling

3. **Exploratory Data Analysis (EDA)**
   - Distribution analysis
   - Correlation analysis
   - Fraud vs non-fraud comparison

4. **Data Partitioning**
   - Train / validation / test split

5. **Modeling**
   - Logistic Regression
   - Random Forest

6. **Model Evaluation**
   - Precision, Recall, F1-score
   - ROC-AUC, PR-AUC
   - Confusion matrix

7. **Threshold Optimization**
   - Cost-based evaluation (false positives vs false negatives)

8. **Triage Analysis**
   - Top-K fraud detection performance
